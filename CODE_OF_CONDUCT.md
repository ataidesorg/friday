# Code of Conduct

Be respectful. Do not harass, insult, or discriminate. Assume good faith in
reviews and issues.

This is a single-maintainer pre-release project. Disagreements get resolved by
the maintainer. Repeated hostile behavior is enough to be asked to leave.

Report security issues through [SECURITY.md](SECURITY.md), not public issues.
Report conduct issues privately to the maintainer via GitHub.
